# MAYSAN INT. GROUP — الموارد البشرية

منصة الموارد البشرية وتحليلات القوى العاملة — لمجموعة ميسان الدولية.

منصة احترافية بمستوى **Power BI Enterprise** مبنية على ملفات Excel الشهرية للموظفين.
ترفع ملف Excel كل شهر، فيقرأه النظام تلقائياً، يفهم أسماء الأعمدة، ينظّف البيانات،
يقارنها بالملفات السابقة، ويحدّث جميع المؤشرات والتقارير والحركات الوظيفية — دون تعديل الكود.

> **الأولويات:** ١) دقة البيانات ٢) جودة التحليل ٣) التقارير الرسمية والطباعة الاحترافية.

**أبرز المزايا الحديثة:**
- **مركز التقارير الرسمية (PDF/طباعة):** مستندات رسمية بترويسة المجموعة والشعار الرسمي،
  ورمز QR إلى linktr.ee/maysan.group، وترقيم الصفحات، وتكرار ترويسة الجداول عبر الصفحات،
  A4 طولي/عرضي — بتصميم فاتح مستقل دائماً حتى في الوضع الداكن.
- **العربية / English** تبديل كامل RTL/LTR للواجهة، **ولغة تقرير مستقلة** (تطبع تقريراً
  بالإنجليزية والواجهة عربية والعكس).
- **الوضع الفاتح / الداكن** (يُحفظ تلقائياً).
- **تعدد الفنادق:** ملف واحد بعمود «الفندق» → عرض الكل / فندق / مقارنة الفنادق، وترحيل
  ذكي يُحدِّث الموظف بدل تكراره عند إعادة الرفع.
- **قواعد التوطين + مطابقة المسميات:** توحيد صيغ المسمى الوظيفي إلى مسمى معياري يُطابَق
  بقرارات التوطين الرسمية القابلة للتحرير من لوحة الإدارة (لا تُخترع نسب رسمية أبداً).
- **الرؤية الذكية:** إخفاء تنبيهات الجواز/العقد للسعودي، والبطاقة الصحية لغير مهن التغذية،
  وفترة التجربة المنتهية — يظهر فقط ما يتطلب إجراءً.

## التشغيل السريع

```bash
npm install
npm start
# افتح http://localhost:3000
# رمز الدخول الافتراضي: 056023   (يُخزَّن Hashed في الخادم، غير مكشوف في الواجهة)
```

لتجربة النظام ببيانات نموذجية:

```bash
npm run seed          # يولّد ملفَّي عيّنة في data/samples (أغسطس ثم سبتمبر 2026)
```
ثم ارفع ملف أغسطس ثم سبتمبر من صفحة «رفع بيانات Excel» لرؤية جميع التحليلات والحركات.

**تعذّر الدخول بالرمز 056023؟** غالباً بسبب ملف حساب قديم محفوظ. أعِد الضبط:

```bash
npm run reset-login   # يحذف حساب الأدمن القديم ليُعاد إنشاؤه بالرمز 056023
npm start
```

متغيّرات بيئية اختيارية: `PORT`, `HR_ADMIN_PASSCODE`, `SESSION_SECRET`.

## المزايا الرئيسية

- **محرّك رفع Excel ذكي** — مطابقة الأعمدة **بالاسم لا بالترتيب** مع درجة ثقة، تحديد الفترة
  من اسم الملف، حقول ديناميكية للأعمدة الجديدة (Flexible Schema)، ولا يُعتمد أي Mapping غير مؤكّد
  دون موافقة المستخدم.
- **فحص وتنظيف البيانات + مؤشر جودة (HR Data Quality Score)** — تكرار الأرقام الوظيفية، الحقول
  الناقصة، التواريخ غير الصحيحة، القيم غير المنطقية، واقتراحات توحيد الجنسيات/الأقسام/المسميات
  (مثل «اندونسيا» ← «اندونيسيا») مع **الاحتفاظ بالقيمة الأصلية والقيمة المطبّعة معاً**.
- **لوحة قيادة تنفيذية** + ملخّص تنفيذي ذكي مبني على أرقام فعلية.
- **تحليلات:** القوى العاملة، السعودة والتوطين، الجنسيات، الأقسام، المسميات، الإجازات والأرصدة،
  الرواتب (بصلاحية خاصة)، الانتهاء والامتثال، رؤى الذكاء الاصطناعي.
- **الحركات الوظيفية** — اكتشاف الترقيات والتعيينات والمفقودين بمقارنة الملفات عبر الرقم الوظيفي،
  مع تصنيف قابل لاعتماد الموارد البشرية، والمقارنة الشهرية ومخطط الشلال، وملف الموظف 360° والمسار الوظيفي.
- **السعودة الرسمية:** تمييز صارم بين **النسبة الداخلية المحسوبة** و**الهدف الرسمي**. لا يُخترع هدف
  توطين — يُجلب فقط من قرار موثّق في «مركز قرارات التوطين» مع المصدر وتاريخ التحقّق؛ وإلا يُعرض:
  «تعذّر تحديد هدف التوطين الرسمي بثقة كافية».
- **الأمان والصلاحيات:** تسجيل دخول Hashed، جلسات آمنة مع مهلة خمول، حماية من محاولات الدخول،
  خمسة أدوار (Admin / HR Manager / HR Officer / Department Manager / Viewer)، وسجل تدقيق كامل.
- **تصميم Enterprise** — RTL، هوية وشعار الشركة، Responsive بالكامل، وطباعة رسمية احترافية بالشعار.

## البنية

```
server.js            خادم Express + REST API + المصادقة والصلاحيات
src/
  schema.js          الحقول الأساسية والمرادفات وتطبيع العناوين
  mapping.js         قراءة Excel + محرّك مطابقة الأعمدة بالاسم
  transform.js       تحويل الصفوف إلى سجلات موظفين (Raw + Normalized)
  normalize.js       اكتشاف التكرارات الإملائية واقتراح التوحيد
  validation.js      الفحص والتنظيف + مؤشر جودة البيانات
  analytics.js       المؤشرات والتوزيعات (بحساب دقيق)
  movements.js       المقارنة التاريخية: ترقيات/تعيينات/مفقودون + المسار الوظيفي
  expiry.js          مركز الانتهاء والامتثال + التنبيهات الذكية
  localization.js    النسبة الداخلية مقابل الهدف الرسمي + تحليل الفجوة
  insights.js        رؤى وملخّص تنفيذي مدعومة بالأرقام
  auth.js store.js dataset.js util.js
public/              واجهة SPA (RTL) + ECharts (vendored محلياً) + طباعة
scripts/generate-sample.js   مولّد بيانات العيّنة (Benchmark)
```

البيانات تُخزَّن كملفات JSON تحت `data/` (لقطات شهرية غير قابلة للتعديل + سجلات).
المكتبات (ECharts / SheetJS) **مضمّنة محلياً** ليعمل النظام دون إنترنت.

## معيار التحقّق (Benchmark)

ملف سبتمبر النموذجي يعطي بالضبط: **104 موظف · 39 سعودي · 65 غير سعودي · 37.50% · 14 قسم ·
41 مسمى · المنشأة: فندق ذا فينيو الحارثية**. أي اختلاف يعني مراجعة الـParser قبل الاعتماد.

## قاعدة أساسية

**لا تُخترع البيانات.** إذا كان Excel لا يحتوي معلومة، تُعرض «غير متوفر / Data Not Available»
ولا تُحسب. جميع النسب محسوبة من القيم الفعلية، والعرض بتنسيق ذكي مع الاحتفاظ بالقيمة الدقيقة للحساب.

## النشر (Deployment) والدومين المخصّص

الواجهة ثابتة من `public/`، وكل `/api/*` يعمل عبر دالة Serverless تستضيف تطبيق Express
(`netlify/functions/api.js` + `netlify.toml`). بيانات الفنادق النموذجية تُشحن من `data/seed/`
فتظهر اللوحات مباشرة على الرابط.

### الدومين المخصّص `mohamad.hr.com`
`mohamad.hr.com` هو **نطاق فرعي لِـ `hr.com`**، ولا يمكن إنشاؤه أو توجيهه إلا من **مالك
`hr.com`** (بإضافة سجل DNS من نوع CNAME لديه). لذلك لا يمكن تهيئته من طرفنا دون تفويض/وصول
من مالك النطاق. البدائل العملية:
- تسجيل نطاق تملكه بالكامل (مثل `maysanhr.com` أو `hr.maysangroup.com` إن كنت تملك
  `maysangroup.com`) وربطه بنقرة من لوحة الاستضافة.
- أو استخدام نطاق فرعي مجاني من مزوّد الاستضافة مؤقتاً.

الإعداد **مرن ومحايد للنطاق**: ربط أي دومين مخصّص يتم من لوحة الاستضافة (Netlify → Domain
management) دون أي تعديل في الكود. لا يوجد أي دومين مثبّت داخل المشروع.

### بناء النسخة المستقلّة (تعمل في المتصفح بالكامل)
```bash
node scripts/build-seed.js data/samples/HR_MultiHotel.xlsx   # يبني seed + embed-data
npx esbuild web/api-shim.js --bundle --format=iife --outfile=web/shim.bundle.js
node web/build-standalone.mjs                                 # ينتج web/standalone.html
```
تُنتج `web/standalone.html` نسخة مكتفية ذاتياً (ECharts + SheetJS + paged.js مضمّنة) —
تُرفع كصفحة واحدة أو تُفتح محلياً، وتدعم رفع Excel والتقارير والطباعة كلها في المتصفح.
