# مجموعة ميسان الدولية — نظام تقييم الأداء (خادم مركزي + روابط تقييم)

MAYSAN INTERNATIONAL GROUP — Hotel Performance Appraisal System with a
**central server database (MySQL)** and **shareable manager evaluation links**.

هذا التطبيق يعمل الآن عبر **خادم مركزي**: كل التقييمات والروابط تُحفظ في قاعدة
البيانات (MySQL) وتتم مشاركتها بين جميع الأجهزة — وليس في متصفح واحد فقط.

---

## ما الجديد

1. **رابط تقييم قابل للمشاركة (أهم ميزة):** من قسم **«روابط التقييم»** ينشئ مسؤول
   الموارد البشرية رابطاً ويرسله للمدير المباشر. يفتح المدير الرابط (بدون تسجيل
   دخول)، ويُدخل المعايير والدرجات، ويُرسل التقييم — فيُحفظ مباشرة في النظام
   ويظهر لدى الموارد البشرية في «السجل» و«لوحة المعلومات».
   - يمكن ربط الرابط بموظف/قسم محدّد (مثلاً **خدمة العملاء** لشخص واحد فقط)،
     أو ترك القسم **مفتوحاً** ليختاره المدير بنفسه.
   - يُحتسب مجموع الدرجة والنسبة على **الخادم** (لا يمكن التلاعب بها من المتصفح).
   - كل رابط يُستخدم مرة واحدة؛ ويمكن إلغاؤه في أي وقت.
2. **تخزين مركزي (MySQL):** كل شيء يُحفظ في قاعدة بيانات النظام. عند عدم إعداد
   MySQL يتحوّل النظام تلقائياً إلى ملف JSON محلي (مناسب لخادم واحد).
3. **تسجيل دخول عبر الخادم:** رمز واحد موحّد في كل مكان (افتراضياً `056023`).

## التشغيل محلياً

```bash
cd appraisal
npm install
npm start
# ثم افتح http://localhost:8090
```

- رمز الدخول الافتراضي: **056023** (غيّره عبر `APPRAISAL_ADMIN_PIN`).
- بدون إعداد MySQL يعمل النظام مباشرة ويحفظ في `data/appraisal-db.json`.

## تفعيل MySQL (للإنتاج والمشاركة بين الأجهزة)

انسخ `.env.example` إلى `.env` واضبط الاتصال:

```
DATABASE_URL=mysql://user:password@host:3306/maysan_appraisal
```

أو المتغيّرات المنفصلة `MYSQL_HOST / MYSQL_USER / MYSQL_PASSWORD / MYSQL_DATABASE / MYSQL_PORT`.

تُنشأ الجداول تلقائياً عند الإقلاع. يمكن أيضاً تطبيق المخطط يدوياً:

```bash
mysql maysan_appraisal < db/schema.sql
```

## النشر (Deployment)

> **مهم:** هذه المنصة تحتاج إلى استضافة تُشغّل **Node.js + MySQL**
> (مثل Railway أو Render أو خادم VPS). لا تعمل على استضافة الملفات الثابتة فقط
> (مثل Netlify الثابت) لأن ميزة «الرابط المشترك + الحفظ المركزي» تتطلب خادماً
> وقاعدة بيانات.

### الخيار الأسهل — Railway أو Render
1. ارفع هذا المجلد إلى مستودع GitHub.
2. أنشئ خدمة **Web Service** من المستودع (أمر التشغيل: `node server/index.js`).
3. أضف قاعدة بيانات **MySQL** من نفس المنصة، وستوفّر لك `DATABASE_URL` — أضفها
   في متغيّرات البيئة.
4. اضبط `APPRAISAL_ADMIN_PIN` (والـ staff pin إن رغبت) لرموز دخول آمنة.
5. انشر — سيتولّى النظام إنشاء الجداول تلقائياً.

### Docker
```bash
docker build -t maysan-appraisal .
docker run -p 8090:8090 --env-file .env maysan-appraisal
```

## بنية المشروع

| المسار | الغرض |
|---|---|
| `server/index.js` | خادم Express + واجهة REST + مسار روابط التقييم |
| `server/store/` | طبقة التخزين: `mysql.js` (إنتاج) و`json.js` (احتياطي) و`index.js` (الاختيار) |
| `server/appraisal-model.js` | يحمّل `data.js` + `scoring.js` نفسها لحساب الدرجة على الخادم |
| `db/schema.sql` | مخطط قاعدة بيانات MySQL |
| `public/index.html` | تطبيق الموارد البشرية (تقييم، تقييم أداء، روابط، سجل، لوحة، إعدادات) |
| `public/invite.html` + `public/js/invite.js` | صفحة المدير المباشر (الرابط المشترك) |
| `public/js/api.js` | طبقة الاتصال بالخادم (تحلّ محل التخزين المحلي القديم) |
| `public/js/data.js` `scoring.js` `report.js` `export.js` `i18n.js` `app.js` | منطق الواجهة والتقارير والتصدير |

## واجهة REST (مختصر)

| الطريقة | المسار | الوصول | الغرض |
|---|---|---|---|
| POST | `/api/auth/login` | عام | تسجيل الدخول بالرمز |
| GET/POST/DELETE | `/api/appraisals` | مصادَق | التقييمات الرقمية |
| GET/POST/DELETE | `/api/performance` | مصادَق/مدير | تقييم أداء الموظف |
| GET/POST | `/api/invites` | مدير | إنشاء/عرض روابط التقييم |
| POST | `/api/invites/:token/revoke` | مدير | إلغاء رابط |
| GET | `/api/public/invite/:token` | عام | سياق الرابط للمدير |
| POST | `/api/public/invite/:token/submit` | عام | إرسال تقييم المدير |

الرابط المشترك يظهر بالشكل: `https://<your-host>/e/<token>`
